# EGX Lite Bot

Simple Telegram bot template for the `EGX Lite Bot` project.

## Setup

1. Activate the existing virtual environment.
2. Install dependencies:
   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```
3. Create a `.env` file based on `.env.example` and set your Telegram bot token.
4. Run the bot:
   ```powershell
   .\.venv\Scripts\python.exe bot.py
   ```

## Available commands

- `/start`
- `/help`
